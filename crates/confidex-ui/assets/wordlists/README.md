# EFF Long Wordlist

`eff-large.txt` is an unchanged copy of the 7,776-word list by Joseph Bonneau
and the Electronic Frontier Foundation, downloaded on 2026-11-09.

- Source: https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt
- Description: https://www.eff.org/dice
- License: Creative Commons Attribution 4.0 International (CC BY 4.0),
  https://creativecommons.org/licenses/by/4.0/
- Copyright policy: https://www.eff.org/copyright

The application embeds this file. Generating a passphrase makes no network
request. It chooses each word independently and uniformly, with replacement,
and joins them with a single space. Dice labels are not part of the password.
